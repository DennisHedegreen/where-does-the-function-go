# Contributing

Start with README.md, docs/METHOD.md and protocol/FREEZE_REGISTER.md. Run the full CPU fixture suite before proposing a change. Keep synthetic fixtures clearly labelled. Include source commit and an inspectable minimal example for discrepancies.

Do not turn fixture PASS into an empirical result or silently alter scientific thresholds. Preserve time-zero artifacts and version protocol changes. Use existing issues or a pull request for technical criticism; avoid personal or sensitive data in public artifacts.
