# Required verification evidence

## Handoff itself

Manifest entries match every payload byte. Captured public paper matches known v0.8 SHA. Article snapshot contains published v1.1 and exact canonical body. Main protocol and original appendices are included without normative rewriting. Open decisions are visible. No source is called independently replicated merely because it is cited.

## Implementation acceptance cases

1. A changed prompt, label, split, model revision, source commit or mask invalidates the corresponding derived artifact lineage. IDs/sorted canonical serialization are stable across worker order.
2. Gate 0 includes all four gates; passing one metric cannot substitute for another. Cases at .08/.05/.03/.10 boundaries and CI crossing/touching zero follow exact published inequalities. Missing metrics cannot pass.
3. Mask fixture tests actual intervention position, untouched coordinates, identity, zeros ≤1e-7, gradient flow and checkpoint reload. Missing hook/model contract aborts.
4. t0 overwrite is refused; a development branch is visibly non-result-bearing and retains original evidence. Training never overwrites t0.
5. B0 equivalence checks both CI ends and paired power. Low power, missing reference validation or materially unstable pool expansion withholds the strongest label. R0–R4 alone cannot authorize it; cross-seed evidence required.
6. Regime fixtures demonstrate EOS allowed at I0, exactly one prohibited EOS step at I0b, configured window at I1 and no new facts in I2. Seeds/splits are deterministic; no aggregation mixes regimes.
7. K unset blocks P3; simulation receipt binds sample-size assumptions, estimator, K comparison, seed and uncertainty criterion. Discovery/tuning/test leakage aborts confirmatory analysis.
8. Fixture PASS cannot become a scientific PASS; synthetic data, unavailable upstream fixture, OOM, invalid shape and hash mismatch have explicit non-scientific status.

Minimum future run manifest: schema/protocol/package versions and hashes; implementation commit + dirty state; source commits; model/tokenizer revisions; dataset/split fingerprints; config; seeds; environment/hardware; run kind; parent IDs; timestamps; artifacts with hashes; software/integrity status; scientific gate evidence; freeze decisions. No arbitrary pickle scientific artifacts.

Minimum new P2 receipts beyond legacy appendix: conditional_backup_effects, candidate_pool_definition, expansion_sensitivity, paired_equivalence_and_power, coax_reference_validation. File formats may be chosen during M0–M3; their evidence cannot be omitted.
