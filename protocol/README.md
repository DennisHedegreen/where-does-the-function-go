# Frozen public protocol baseline

Article 200 v1.1 and Camelot MI-001 v0.8, as published before implementation.

Article: https://hedegreenresearch.com/articles/where-does-the-function-go/
Paper: https://hedegreenresearch.com/assets/camelot/reports/model-internals/where-does-the-function-go/model-internals__intl__2026-09__i001__v0-8__draft.pdf

This public subset of WDFG_Codex_Handoff_v0.2 excludes private publishing receipts and site HTML. Its manifest differs deliberately from the original editorial package; the scientific paper PDF hash is unchanged. Sources under sources/protocol are reading references, not a complete LaTeX build kit.

The working paper governs scientific requirements. Implementation documents map those requirements and record unresolved discrepancies. Software tests do not validate the scientific hypotheses. See FREEZE_REGISTER.md before proposing empirical work.

Existing source snapshots retain their original rights and notices; the repository MIT license does not relicense the archived paper or article. Documentation-only later publications do not silently change this baseline.
